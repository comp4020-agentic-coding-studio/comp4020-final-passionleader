## About ANU Crossing

Made by passion leader ([GitHub](https://github.com/passionleader)), for COMP8020
Agentic Coding Studio at the Australian National University (Semester 2, 2026). An
unofficial student project, not an ANU service. The course provided the hosting, the
repository and the Claude Code credits it was built with, and
[the code is on GitHub](https://github.com/comp4020-agentic-coding-studio/comp4020-final-passionleader).

I planned it, photographed and drew the campus, chose the music, set up AWS and
tested it live on my own phone. The code was written with several Claude Code
sessions working together.
